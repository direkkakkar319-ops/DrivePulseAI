# KIT anomaly research archive

- `data/kit_obd/`: raw source chunks, locally reassembled recordings when
  available, and prepared 10-second windows.
- `models/`: historical next-window novelty estimator, preprocessing/training
  scripts, and experiment artifacts/reports.

This is not the active Nissan Leaf anomaly model. The retired KIT serving
application, deployment notes, model code copies, and artifact are preserved
under `deployment/` and `models/` for reference. The KIT request contract is no
longer served by the active ML application.
